# Lab 7 — Sass Gallery Portal

## Ubuntu / VS Code
```bash
npm install
npm run build
```
Open `index.html` with Live Server. For editing: `npm run dev`.

Sass maps, custom properties, mixins, functions, partials, BEM, @each utilities, compressed CSS and flip cards included.

Note: This is a reconstructed example based on the CSS supplied in chat, not a pixel-identical copy of the original HTML.
